# Workshop Prerequisites Messaging (Attendee-Ready)

## Full Prerequisites Message

Hello and welcome to the AI Coding Workshop at Beer City Code! Shawn and I are excited you are joining us. This is a hands-on session where you will work through guided labs and use either GitHub Copilot or Claude Code to generate, refine, and validate code. To help you get the most from the workshop, please complete the setup below before we begin.

### Before the workshop starts
- Clone the workshop repository to your machine - https://github.com/mcollier/ai-dev-workshop
- Review and complete the [Getting Started instructions](https://github.com/mcollier/ai-dev-workshop/docs/README) in the repository
- Recommended setup path: open the repository in the provided Dev Container to bootstrap the environment quickly and consistently

### Required software and connectivity
- VS Code installed (**version 1.98+ required**)
- Reliable internet connection (required for GitHub Copilot or Claude Code usage)

### Required AI assistant access (mandatory)
Please make sure **either Claude Code or GitHub Copilot** is available and working before the workshop.  
These tools are required for the hands-on exercises, so attendees without one may not be able to complete the labs as designed.
- Confirm authentication before workshop day (sign in and verify you can get a response/suggestion).

### Important cost/credits notice
This workshop uses live AI coding workflows that consume model tokens/credits during labs.  
That usage can result in real cost, or use credits included in your existing plan/subscription, so please plan accordingly.

### Quick day-of check (5 minutes before)
- Pull latest changes from the workshop repository
- Open the project in VS Code (Dev Container recommended)
- Confirm your chosen AI assistant is authenticated and responding
