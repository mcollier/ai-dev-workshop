# Story 9: Sort Tasks by Priority

**As a** task manager user
**I want** to sort my task list by priority
**So that** high-priority tasks appear at the top of my list

## Acceptance Criteria

- [ ] `GET /tasks?sortBy=priority` sorts High → Medium → Low
- [ ] `sortOrder=desc` reverses the order (Low → Medium → High)

**Dependencies:** Stories 1, 2, 3
**Estimate:** 2 points
**Priority:** Low
